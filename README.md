# MyPocket-App
# 💸 MyPocket - Gestión Financiera Inteligente

MyPocket es una aplicación de escritorio desarrollada en **Java** diseñada para ofrecer un control total sobre las finanzas personales y de pequeñas empresas.

## ✨ Características principales
* **Dashboard:** Vista rápida de tu saldo y últimos movimientos.
* **Hucha Acumulativa:** Establece metas de ahorro que se suman mes a mes.
* **Simulador de Interés Compuesto:** Proyecta tus ahorros a futuro con estética Dark Mode.
* **Seguridad Local:** Base de datos persistente mediante SQLite/Oracle.

## 🚀 Cómo usar la aplicación (Sin instalar Java de Oracle)
Si eres usuario final y no quieres configurar el entorno de desarrollo:
1. Descarga el archivo `MyPocket.jar` de la sección **Releases**.
2. Asegúrate de tener la carpeta del ejecutable descargada.
3. Ejecuta el acceso directo (configurado con `javaw.exe`) para abrir la app sin consolas de fondo.
