# MyPocket-App
# 💸 MyPocket - Gestión Financiera Inteligente

MyPocket es una herramienta robusta de escritorio construida en **Java** para quienes buscan un control total de sus finanzas. No solo registra gastos, sino que gestiona metas de ahorro reales y proyecta tu futuro financiero.

---

## 🚀 Guía de Instalación Rápida

Sigue estos pasos para tener la app funcionando en menos de 5 minutos:

### 1. Preparar la Base de Datos (Oracle)
La aplicación requiere una instancia de Oracle Database. Abre tu terminal SQL (SQL Plus o SQL Developer) y ejecuta:

```sql
--Crear usuario y dar permisos
CREATE USER c##mypocket IDENTIFIED BY micasa123;
GRANT CONNECT, RESOURCE, DBA TO c##mypocket;
ALTER USER c##mypocket QUOTA UNLIMITED ON USERS;

-- Crear tablas necesarias
CREATE TABLE usuarios (
    username VARCHAR2(50) PRIMARY KEY,
    password VARCHAR2(50) NOT NULL,
    fecha_creacion DATE DEFAULT SYSDATE
);

CREATE TABLE movimientos (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    tipo VARCHAR2(20),
    subtipo VARCHAR2(20),
    cantidad NUMBER(10,2),
    concepto VARCHAR2(100),
    fecha DATE DEFAULT SYSDATE
);

CREATE TABLE configuracion (
    id NUMBER PRIMARY KEY,
    meta_ahorro NUMBER(10,2) DEFAULT 0
);

INSERT INTO configuracion (id, meta_ahorro) VALUES (1, 0);
COMMIT;
2. Descargar la Aplicación
Ve a la sección de Releases.

Descarga el archivo MyPocket_v1.exe (o el .zip si prefieres el JAR).

3. Iniciar la App
Haz doble clic en el ejecutable.

Si es la primera vez, crea un usuario en la pantalla de Login y ¡listo!

🔄 Sistema de Actualizaciones
La aplicación incluye un botón inteligente de "Actualizar App 🔄" en el panel principal.

Si sale una nueva versión con mejores gráficas o funciones, recibirás una notificación dentro de la app.

Al pulsar el botón, serás redirigido automáticamente a este repositorio para descargar el nuevo ejecutable sin perder tus datos de la base de datos local.

🛠️ Solución de Problemas (FAQ)
¿La app no se abre al hacer doble clic?

Comprueba que tienes instalado Java 21 o superior. Puedes verificarlo en tu consola con java -version.

Asegúrate de que el servicio de Oracle esté iniciado en tu sistema.

¿Error de conexión?
Revisa que el usuario creado sea c##mypocket con la contraseña micasa123. Si usas otros datos, deberás compilar tu propia versión con los accesos actualizados.
